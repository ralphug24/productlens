# ProductLens

Product teardown and competitive strategy studio.

ProductLens brings competitor comparisons, user journey reviews, unmet needs, and feature proposals into one evidence trail. This static prototype uses illustrative data to show the workflow; competitor observations and user quotes are fictional and have not been independently verified.

## Open the prototype

Open `index.html` in a modern browser. No build step or server is required.

The prototype includes:

- A capability comparison across products
- Clickable stages in a first-session journey
- Evidence panels for quotes, review themes, and research sources
- Ranked unmet needs
- A proposal form connecting a need to a product bet and success signal
- A JSON export of the current teardown

Edits made in the proposal form are kept in the current browser session only. The prototype has no backend, account system, live competitor data, or persistent storage.
